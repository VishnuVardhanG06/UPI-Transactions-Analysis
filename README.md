📊 UPI Transactions Data Analysis (Power BI)
🎯 Project Overview

This is an interactive Power BI dashboard built to analyze UPI transaction data and provide insights into transaction patterns, user behavior, and financial trends.

🔍 Key Components Identified

Filters (Slicers):

Bank Name (Sender)
Bank Name (Receiver)
City
Device Type
Gender
Age Groups
Merchant Name
Payment Method
Purpose
Transaction Type
📈 Visualizations & Insights

1. Monthly Transaction Trends

Transaction amounts are analyzed month-wise (January–December).
Users can identify peak and low transaction periods.

2. Purpose-wise Analysis

Transactions are categorized into:
Shopping
Travel
Bill Payment
Food
Others

This helps understand spending behavior.

3. City-wise Analysis

Remaining balance is analyzed across different cities.
Allows comparison of financial activity by location.

4. User Segmentation

Transactions can be explored based on:
Gender
Age groups
Device type

5. Banking Analysis

Analysis of transactions between different banks (sender and receiver).
